# 当前版本：星芒落点（Spark Drop）

**一句话**：一枚放射的星芒，最下面那一道伸长成下载箭头，落在一条横线上。

这个软件的代码几乎都由 Claude 编写，图标向 Claude 致敬：陶土橙配象牙白，用的是 Anthropic 的品牌色（橙 `#d97757`、象牙白 `#faf9f5`、浅灰 `#e8e6dc`、深色 `#141413`）。星芒是重新设计的原创图形，不是 Claude 的官方标志，也不代表本软件和 Anthropic 有任何官方关系。

- **星芒**：十个方向，九道光芒长短交错、根粗尖圆，带一点手绘的不规则感，温暖而不机械。
- **下载**：正下方那一道没有停在光芒的长度，而是继续伸长，变成圆角箭头——灵感落地，变成文件。箭头两侧的光芒稍短，和箭头之间留出空隙，缩小后「下载」依然一眼可辨。
- **落点**：深灰色的横线是文件停靠的地方，沿用旧图标「棱镜落点」的落点概念，和橙色星芒区分开。
- **小尺寸**：32 像素及以下自动加粗、整体放大；安卓按自适应图标规范分层（背景、前景、主题单色层），通知栏小图标是同一剪影。

重新导出（项目根目录）：`.\.venv\Scripts\python.exe 图标设计\星芒落点\draw_icon.py`，会同时更新 `app/icon.ico`、安卓各档图标和通知栏图标；加 `--preview` 只生成预览图。

# 旧版：棱镜落点（Prism Drop）

**一句话**：把"播放"转向下方，它就成了"下载"。

一个形状两种身份。播放键本是向右的三角，旋转九十度后指向下方，成了下载的箭头。图标里不放第二个符号，也不加文字或装饰，只有这个三角和它落下去的那条线。识别全靠这一个形状。

三角被两道细缝横切成三层，暗指"解析"：一条链接被拆开，分出不同的流和清晰度。三层由上到下越来越实。最上层像半透的玻璃，越往下越凝实，最后汇到最亮的那一点。这是在讲多条流合并成一个文件，但不写出来，看懂的人会心一笑，看不懂的人只看到一个干净的形状。细缝的宽度要反复推敲：大图上清晰可见，缩到 32 像素以下就整体收拢成实心三角，保证在任务栏和通知栏里依旧利落。

底下那条横线是"落点"，是文件最终停靠的地方。它与三角尖端之间留出的距离，是整个图标的呼吸。太近就显得拥挤，太远两者又不像一体，必须细细调到恰好。

色彩只用一组：靛蓝到紫的斜向渐变，左上角有一团更亮的光，像玻璃板被光照着。边缘有一道极细的高光，暗示材质，但不喧宾夺主。白色是唯一的前景色。

每一处圆角、每一个间距都按像素校准，大小尺寸分别绘制而不是简单缩放。它应当看上去像是被反复打磨过的成品：放在桌面上安静、可信，一眼就能认出来。
