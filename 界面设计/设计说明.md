# 界面设计：向 Claude 应用看齐

这个软件的代码几乎都由 Claude 编写，界面因此向 Claude 应用致敬。目标是不看文字也能认出来：「这一定是 Claude 做的」。
这些都是原创实现（自绘控件、自画图标），没有使用 Anthropic 的素材，也不代表与 Anthropic 有任何官方关系。

预览：[电脑版界面预览.png](电脑版界面预览.png)（左上浅色首页、右上深色首页、左下解析结果与下载进度、右下设置）。

## 一眼认出的几处

- **首页**：橙色星芒 + 衬线大字问候语（「晚上好，Moyer」「周一快乐，Moyer」，按时段 / 星期随机），下面是居中的圆角大输入框。
- **输入框**：大圆角、柔和投影；左下角「+」和功能胶囊（封面 / 弹幕 / 字幕，打开后变淡橙色），右下角陶土橙方形发送箭头；
  框外下方左边是文件夹选择，右边是「清晰度」选择（对应 Claude 的项目选择和模型选择）。Enter 发送，Shift+Enter 换行。
- **侧边栏**：衬线字的软件名，橙色圆底「+」新建，下载 / 历史记录，「最近下载」列表，左下角头像 + 名字 + 账号状态，点开是账号菜单。
- **设置**：盖在窗口上的面板，左边分类、右边「标题 + 灰色说明 / 开关」一行一行，改了立即生效，没有「保存」按钮。
- **「思考中」动画**：解析时星芒一根根伸缩、下载箭头轻轻点头（同 Claude 回复时的星芒动画）。

## 颜色（app/theme.py 的令牌）

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| bg | `#faf9f5` | `#262624` | 主背景（象牙白 / 暖深灰） |
| sidebar | `#f3f1ea` | `#1f1e1d` | 侧边栏 |
| surface | `#ffffff` | `#30302e` | 卡片、输入框、菜单 |
| text / text3 | `#141413` / `#73726c` | `#faf9f5` / `#a6a39a` | 正文 / 次要文字 |
| brand | `#d97757` | 同左 | 星芒、进度条 |
| accent | `#c96442` | 同左 | 发送按钮、开关打开、勾选的胶囊 |
| primary | `#141413` | `#faf9f5` | 主按钮（浅色是黑底白字，深色反过来） |
| ok / err / info | `#55733a` / `#b3452f` / `#3c6a9c` | 提亮版 | 完成 / 失败 / 处理中 |

橙色只用在少数地方（星芒、发送、开关），主按钮用黑色，大面积是暖白 / 暖灰。

## 字体与形状

- **中文一律用系统黑体**（电脑微软雅黑、手机系统字体）——和 Claude 一样：Claude 的「周一快乐，Moyer」是中文黑体 + 英文衬线。
- **英文**：Claude 用的是 Anthropic 自己的商用字体（不能随软件分发），这里用最接近的开源字体（SIL OFL 1.1，见 `app/fonts/OFL.txt`）：
  正文 **VDSans**（Hanken Grotesk）、问候语和标题 **VDSerif**（Source Serif 4），只截取拉丁字母，合计不到 0.3 MB。
  重新生成：`.venv\Scripts\python.exe 图标设计\字体\make_fonts.py`（源文件在 `图标设计/字体/源文件/`）。
- 圆角：输入框 20、卡片 14～16、按钮 8、胶囊全圆。边框 1px 半透明暖灰，几乎不用阴影（只有输入框有一点）。
- 图标：`app/icons.py`，24×24 圆头细线（1.75px），全部手绘几何图形。

## 安卓版

预览：[安卓版界面预览.png](安卓版界面预览.png)（浅色首页、解析结果、深色下载完成、设置）。对照的是 Claude 手机版：

- **首页**：左上角汉堡菜单、右上角下载（带数量角标）；中间星芒在上、衬线问候语在下；底部圆角输入框：
  左边「+」（粘贴 / 下载选项 / 网站登录信息）和选项胶囊（显示「字幕 · 弹幕版」，点开是底部弹出的开关列表），
  右边圆形按钮：没输入时是黑色「粘贴并解析」，有输入时变成橙色发送箭头。
- **侧边栏**：衬线软件名，下载 / 历史记录 / 设置，「最近下载」列表，底部头像 + 黑色「+ 解析新链接」。
- **设置页**：返回箭头 + 居中标题，B站账号卡片（大会员是黑色胶囊，对应 Claude 的 Pro），分组白卡片，每行「图标 + 标题 + 灰色说明 + 开关 / 箭头」。
- 下载进度直接显示在视频卡片底部；提示是底部深色胶囊；浅色 / 深色可跟随系统。

代码：`Theme.kt`（颜色令牌，和电脑版一致）、`Ui.kt`（Spark 星芒动画、卡片、按钮、设置行、提示）、
`LineIcons.kt`（由 `界面设计/gen_android_icons.py` 从电脑版图标生成）、`Greetings.kt`（问候语，规则同 `app/greetings.py`）、
`res/font/vdsans_*.ttf`、`vdserif_*.ttf`（同电脑版的英文字体）、`AvatarEditor.kt`（头像框选）。

## 分区与平台 logo

- 侧边栏「分区」像 Claude 的「项目」：内置 B站 / X / YouTube / 抖音 / 快手，下载时按平台自动放进去；可以新建分区（名称 + 从图标库选图标），
  把视频「移至分区」。数据在 `app/history.py`（电脑版、手机版共用）。
- 平台 logo「有其形、无其色」：取官方 logo 的形状，用主题文字色单色显示（浅色主题深灰、深色主题象牙白），和线条图标放在一起不突兀。
  来源和生成：`界面设计/make_logos.py` → `app/brand_logos.py`；预览 `图标设计/平台logo/单色logo预览.png`。
- 自建分区的图标库：`app/icons.py` 的 `SECTION_ICONS`（30 个，同样的细线风格）；安卓由 `gen_android_icons.py` 生成。
- 搜索：电脑版侧边栏「搜索」（Ctrl+K，盖在窗口上的搜索框）；手机版侧边栏右上角的放大镜。

## 网盘分享（2.0，电脑版和安卓版）

- 视频和网盘共用一个输入框：粘贴的文字里网盘分享链接交给网盘引擎（`app/pan.py` ↔ `pan-engine.exe`），其余的交给 yt-dlp；
  解析页里两种卡片混在一起，最新的在最上面。
- 网盘卡片和视频卡片同一个骨架：左边 176×99 的「封面」位置换成浅灰底 + 网盘 logo（单色），右边标题、平台标签、文件数和大小；
  下面是文件树（Claude 风格的细边框圆角列表，黑底白勾的复选框，文件夹半选时显示一条横线），最下面是保存位置 + 黑色「下载」。
  只有一个文件的分享不显示文件树。需要登录时标题下面一行黄色提示 + 黑色「扫码登录」按钮，「下载」变灰。
- 一次下载 = 一个批次：卡片下方一条进度（和视频卡片里的下载进度一样），「下载」页一张卡片（logo 小封面 + 总进度，⌄ 展开每个文件）。
- 侧边栏「分区」分成「视频分区」「网盘分区」两组，各自有「+」。视频分区放下载好的视频；网盘分区放网盘分享的**解析记录**
  （网盘文件下载后常被移走、解压，所以只记分享链接，点一下重新解析）。「最近下载」只放下载好的视频。
- 历史记录页 = 解析记录：筛选 全部 / 视频 / 网盘，「已下载的视频」切到下载记录；选了网盘或已下载后再列出对应的分区。
- 安卓版：网盘卡片、文件树（三态勾选）、下载页批次卡片、扫码登录窗口（多一个「保存二维码」，因为手机扫不了自己的屏幕）都和电脑版一致，
  代码在 `PanEngine.kt`（启动引擎、通信）、`PanModel.kt`（状态与操作）、`PanUi.kt`（界面）。
- 扫码登录是一个小窗口：白底圆角里放二维码（深色模式也保持白底，方便扫），下面一行状态（等待扫码 / 已扫码请确认 / 已过期）。
- 代码：`app/pan_ui.py`（PanCard、PanTree、PanBatchView、QRLoginDialog、CaptchaDialog、PanMixin），引擎协议见 `pan/cmd/pan-engine/main.go` 开头的说明。

## 头像

- 像手机系统和社交软件的头像裁剪：深色底上放图片，圆形取景框外压暗、白色细圈，拖动时圈里显示三等分线；缩放滑块是对数刻度（中间 ≈ 2.8 倍，最大 8 倍）；
  旋转 90°；实时预览（电脑版右边三种尺寸，最小的就是侧边栏的大小；手机版下方两个）。圆始终完整落在图片里，不会裁出空白。
- 保存 512×512 的圆形 PNG（圆外透明），同时存原图（长边 ≤ 2048）和 `crop.json`（`cx`、`cy` 是旋转后图片上的相对位置，`zoom` ≥ 1，`rot`），
  「调整位置」时原样还原。电脑版 `app/avatar.py`（程序目录 `avatar/`），手机版 `AvatarEditor.kt`（App 私有目录 `files/avatar/`）。
- 没有头像时仍是陶土橙圆底 + 名字首字母，和以前一样。

## 代码结构

- `app/theme.py`：颜色令牌、浅色 / 深色、样式表；`theme.apply(app, 'system' | 'light' | 'dark')` 随时切换。
- `app/ui.py`：自绘组件（Spark 星芒、Composer 输入框、IconButton、Chip、NavItem、Card、Toggle、ProgressLine、Toast、Overlay…）。
- `app/gui.py`：主窗口（侧边栏 + 解析 / 下载 / 历史 / 日志四页）；`app/settings_dialog.py`：设置面板。
- Win11 标题栏和窗口同色（DWM），菜单 / 下拉列表系统圆角。
