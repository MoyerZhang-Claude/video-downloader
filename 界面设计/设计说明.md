# 界面设计：向 Claude 应用看齐

这个软件的代码几乎都由 Claude 编写，界面因此向 Claude 应用致敬。目标是不看文字也能认出来：「这一定是 Claude 做的」。
这些都是原创实现（自绘控件、自画图标），没有使用 Anthropic 的素材，也不代表与 Anthropic 有任何官方关系。

预览：[电脑版界面预览.png](电脑版界面预览.png)（左上浅色首页、右上深色首页、左下解析结果与下载进度、右下设置）。

## 一眼认出的几处

- **首页**：橙色星芒 + 衬线大字问候语（「晚上好，Moyer」「周一快乐，Moyer」，按时段 / 星期随机），下面是居中的圆角大输入框。
- **输入框**：大圆角、柔和投影；左下角「+」和功能胶囊（封面 / 弹幕 / 字幕，打开后变淡橙色），右下角陶土橙方形发送箭头；
  框外下方左边是文件夹选择，右边是「清晰度」选择（对应 Claude 的项目选择和模型选择）。Enter 发送，Shift+Enter 换行。
- **侧边栏**：衬线字的软件名，橙色圆底「+」新建，下载 / 历史记录，「最近下载」列表，左下角头像 + 名字 + 账号状态，点开是账号菜单。
- **设置**：盖在窗口上的面板，左边分类、右边「标题 + 灰色说明 / 开关」一行一行，改了立即生效，没有「保存」按钮。
- **「思考中」动画**：解析时星芒一根根伸缩、下载箭头轻轻点头（同 Claude 回复时的星芒动画）。

## 颜色（app/theme.py 的令牌）

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| bg | `#faf9f5` | `#262624` | 主背景（象牙白 / 暖深灰） |
| sidebar | `#f3f1ea` | `#1f1e1d` | 侧边栏 |
| surface | `#ffffff` | `#30302e` | 卡片、输入框、菜单 |
| text / text3 | `#141413` / `#73726c` | `#faf9f5` / `#a6a39a` | 正文 / 次要文字 |
| brand | `#d97757` | 同左 | 星芒、进度条 |
| accent | `#c96442` | 同左 | 发送按钮、开关打开、勾选的胶囊 |
| primary | `#141413` | `#faf9f5` | 主按钮（浅色是黑底白字，深色反过来） |
| ok / err / info | `#55733a` / `#b3452f` / `#3c6a9c` | 提亮版 | 完成 / 失败 / 处理中 |

橙色只用在少数地方（星芒、发送、开关），主按钮用黑色，大面积是暖白 / 暖灰。

## 字体与形状

- 标题（问候语、页面标题、软件名）：衬线字体 **VDSerif**（思源宋体截取常用字，SIL OFL 1.1，见 `app/fonts/OFL.txt`；
  重新生成：`.venv\Scripts\python.exe 图标设计\字体\make_serif_font.py`）。正文：微软雅黑。
- 圆角：输入框 20、卡片 14～16、按钮 8、胶囊全圆。边框 1px 半透明暖灰，几乎不用阴影（只有输入框有一点）。
- 图标：`app/icons.py`，24×24 圆头细线（1.75px），全部手绘几何图形。

## 安卓版

预览：[安卓版界面预览.png](安卓版界面预览.png)（浅色首页、解析结果、深色下载完成、设置）。对照的是 Claude 手机版：

- **首页**：左上角汉堡菜单、右上角下载（带数量角标）；中间星芒在上、衬线问候语在下；底部圆角输入框：
  左边「+」（粘贴 / 下载选项 / 网站登录信息）和选项胶囊（显示「字幕 · 弹幕版」，点开是底部弹出的开关列表），
  右边圆形按钮：没输入时是黑色「粘贴并解析」，有输入时变成橙色发送箭头。
- **侧边栏**：衬线软件名，下载 / 历史记录 / 设置，「最近下载」列表，底部头像 + 黑色「+ 解析新链接」。
- **设置页**：返回箭头 + 居中标题，B站账号卡片（大会员是黑色胶囊，对应 Claude 的 Pro），分组白卡片，每行「图标 + 标题 + 灰色说明 + 开关 / 箭头」。
- 下载进度直接显示在视频卡片底部；提示是底部深色胶囊；浅色 / 深色可跟随系统。

代码：`Theme.kt`（颜色令牌，和电脑版一致）、`Ui.kt`（Spark 星芒动画、卡片、按钮、设置行、提示）、
`LineIcons.kt`（由 `界面设计/gen_android_icons.py` 从电脑版图标生成）、`Greetings.kt`（问候语，规则同 `app/greetings.py`）、
`res/font/vdserif.ttf`（同电脑版的衬线字体）。

## 代码结构

- `app/theme.py`：颜色令牌、浅色 / 深色、样式表；`theme.apply(app, 'system' | 'light' | 'dark')` 随时切换。
- `app/ui.py`：自绘组件（Spark 星芒、Composer 输入框、IconButton、Chip、NavItem、Card、Toggle、ProgressLine、Toast、Overlay…）。
- `app/gui.py`：主窗口（侧边栏 + 解析 / 下载 / 历史 / 日志四页）；`app/settings_dialog.py`：设置面板。
- Win11 标题栏和窗口同色（DWM），菜单 / 下拉列表系统圆角。
