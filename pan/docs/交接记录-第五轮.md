## 决定：百度临时转存回退暂不实现

- 实测的他人百度分享全部能直接下载；百度最可能拦截下载的情况（图片验证码）Codex 已做人工输入流程。
- 回退需要“下载自己网盘文件”的另一套非公开接口（网页版需要主页签名，PCS 旧接口需另行验证），在没有任何真实失败样本时实现，只能靠猜测和模拟测试，风险大于收益。
- 以后遇到“直接下载失败且不是验证码/登录/分享失效”的真实链接时再做；届时按第四轮记录的“任务隔离临时目录 + 先同步保存所有权再转存”方案实现。

## 安卓版（M6 第一步：可安装的 APK）

产物：`bin/PanDL-0.5.0.apk`（不进 Git），包名 `com.pandl.app`，版本 0.5.0（versionCode 5），
同时含 arm64-v8a（手机）和 x86_64（模拟器）的 Go 库；正式版构建，用本机调试证书签名（APK 签名 v2 校验通过）。

### 编译环境（本机）

| 组件 | 情况 |
|---|---|
| Android SDK | `%LOCALAPPDATA%\Android\Sdk`（Android Studio 已装：build-tools 36、platform 37、模拟器、API 37 镜像）；compileSdk 35 的平台包由 Gradle 自动补装 |
| NDK | 本轮从 dl.google.com 下载 r27d（27.3.13750724，SHA1 已核对），解压到 `Sdk/ndk/27.3.13750724` |
| JDK | Android Studio 自带 `D:\AI\Android Studio\jbr`（JDK 25） |
| Gradle / AGP | 工程自带 wrapper：Gradle 9.2.1、AGP 8.7.3 |

- **Wails 自带的安卓编译任务（`wails3 task android:*`）只支持 macOS/Linux 主机**（检测 `uname`，Windows 直接报 “Unsupported host OS”）。
  新增 `scripts/build-android.sh`，用 Windows 版 NDK 编译器（`*-clang.cmd`）做同样的步骤：生成入口 overlay → 编译前端 → 分架构 `go build -buildmode=c-shared` → `gradlew.bat assembleRelease` → 复制到 `bin/PanDL-<版本>.apk`。
- JDK 25 会让 AGP 的发布前 lint 崩溃（错误信息只有 “25.0.3”），在 `app/build.gradle` 里设置 `lint { checkReleaseBuilds false; abortOnError false }`。

### 验证情况

- Go：`GOOS=android CGO_ENABLED=0 go vet` 通过；真实 NDK + cgo 编译两个架构的 `libwails.so` 成功；全部 Go 测试、前端测试、类型检查通过。
- APK：`aapt2 dump badging` 确认包名/版本/权限/两个架构；`apksigner verify` 通过。
- 布局：用浏览器测试模式在 375×812 下检查主界面、任务行和账号窗口，没有溢出。
- **没有在真机或模拟器上运行过**：本机模拟器报“x86_64 emulation currently requires hardware acceleration”（未安装 Android Emulator hypervisor driver，也未启用 Windows 虚拟机平台）。安装驱动属于系统设置变更，没有代为操作。

### 真机上需要重点验证

1. 启动是否正常（Go 入口、私有目录、Keystore 密钥生成）。
2. 权限引导：通知权限、“所有文件访问权限”跳转；拒绝后主界面的存储提示。
3. 扫码登录（截屏 + 网盘 App 相册识别）后账号能保存、重启后仍在。
4. 下载到 `下载/PanDL`、通知栏进度、锁屏/切后台继续下载、全部完成后通知消失。
5. 复制链接后切回软件自动弹出解析窗口（安卓 12+ 会出现系统“已读取剪贴板”提示，属正常）。
6. 点“打开”是否弹出“打开方式”选择器并能用其他应用打开（FileProvider 的 external-path 配置）。
