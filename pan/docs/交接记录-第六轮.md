## 界面改版

设计要点：

- 纯色背景（浅色 `#E8ECF2`、深色 `#0F1218`，跟随系统主题）；面板是半透明白 + `backdrop-filter` 模糊 + 细白描边 + 柔和阴影；
  弹窗遮罩同样模糊背后的界面，磨砂效果最明显。强调色取图标的蓝（`#2F6BFF`）。
- 线条图标（`frontend/src/components/Icon.vue`，自绘路径，无新依赖）；按钮分主按钮 / 普通 / 透明 / 仅图标；标签页改成分段选择器；开关改成滑块。
- 顶栏只显示各网盘的登录状态点（不再显示昵称——123 的昵称是手机号）、实时总速度和下载数。
- 任务行：按网盘着色的文件图标、文件名、细进度条、一行状态（平台 · 状态 · 校验标签 · 大小 · 百分比），右侧图标按钮。
- 手机（宽度 ≤ 600px）：弹窗变成底部滑出面板；标签页单独一行；任务行去掉左侧图标和连接数；
  顶部/底部按系统安全区域留白（修复状态栏与标题重叠），状态栏图标深浅跟随主题；安卓窗口底色与界面一致（含深色模式）。
- 分享窗口底部的选择统计改为只说实际选中的内容（原来“已选 0 个文件（0 B）、1 个文件夹”）。

## 安卓签名

- 签名不需要 USB 调试，在电脑上完成。
- 为了让用户手机上已安装的 0.5.0 能**直接覆盖升级**（不丢账号和任务），把当时签名用的本机调试证书导出成 PanDL 专用证书：
  `build/android/keystore/pandl-signing.jks`（别名 `pandl`，PKCS12，随机强密码），密码在同目录 `signing.properties`。整个目录被 `.gitignore` 排除。
- 证书 SHA-256：`d3df2a3abcaf9add45ea4bdaed8b1f68383e502ff013cd70c6969aa9048c7354`（与 0.5.0 相同；0.6.0 已用 apksigner 核对）。
- `scripts/build-android.sh` 发现 `signing.properties` 时自动用它签名；**丢失这两个文件就无法再发布可覆盖安装的更新**，需要另行备份。换电脑编译时把整个 `build/android/keystore/` 拷过去即可。
- 证书名称仍显示 “Android Debug”，只是名字，对自用无影响；如果以后要上架应用商店，需要另建正式证书（届时用户需卸载重装一次）。
