# PanDL 0.5 阶段验收

日期：2026-10-22。范围：M0–M6 第一步（电脑版 0.5.0、安卓版 0.5.0）。
“实测”指用真实账号、真实网盘链接操作过；“模拟”指只在本地模拟服务器 / 自动化测试里验证过。

## 一、需求对照

| 用户最初的要求 | 结论 |
|---|---|
| 识别百度、夸克、123、Mega 等分享链接（粘贴整段文案也行） | ✅ 实测（四个平台 + 普通直链；提取码自动识别，缺失或错误时弹窗输入） |
| 登录自己的账号后，下载速度与官方客户端一致 | ✅ 实测：百度 SVIP 电脑 12.4 MB/s（跑满 100M 宽带）、手机 18.1 MB/s；123 约 13 MB/s；夸克 8.5–12.4 MB/s（夸克侧会临时限速） |
| 免转存下载 | ✅ 百度、123、Mega 真·免转存；夸克平台只允许下载自己网盘里的文件，改为“临时转存 → 下载 → 自动删除”，对用户操作完全一样（实测） |
| 下载队列：暂停、继续、失败重试、速度统计 | ✅ 实测 + 自动化测试（多连接分段、断点续传、重启后自动继续、自动/手动重试、实时速度与剩余时间） |
| 需要提取码的链接由用户手动输入 | ✅ 实测 |
| 安卓版 | ✅ 用户真机实测：别人的百度、夸克分享识别和下载正常 |

## 五、遗留问题与风险

1. **签名**：APK 目前用电脑上的调试证书签名，换电脑编译的版本无法覆盖安装。下一版改为专用证书（见第五轮交接后续）。
2. **百度转存回退**：没有真实失败样本，暂不实现。
3. **非公开接口**：各网盘接口随时可能改版，坏了只需修对应平台的适配器。
4. **界面**：功能优先的朴素界面，下一阶段做统一的视觉设计（简约 + 磨砂玻璃 + 纯色背景）。
5. 手机顶部状态栏与标题重叠；顶部直接显示账号昵称（123 是手机号）。下一阶段一并修正。

## 结论

0.5 阶段的功能目标全部达成，电脑版和安卓版都已在真实环境跑通，可以进入界面设计阶段。
