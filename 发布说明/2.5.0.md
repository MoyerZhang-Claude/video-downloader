## 更新内容

### 新功能
- [电脑版] **网站登录**：要登录才能看的视频，在 设置 → 网络与登录 里点「登录」，在内置浏览器（电脑上的 Edge / Chrome，用的是软件自己的独立配置）里登录就行，不用再装浏览器扩展导出 cookies；登录信息会自动刷新，失效了卡片上有「去登录」
- [安卓版] **网站登录**：TikTok、X、Instagram、Vimeo 等网站可以在 设置 → 网站登录信息 里直接打开网页登录；YouTube 和其它网站仍然可以导入 cookies
- [电脑版] **网页资源嗅探**：解析不了的网站，点输入框的 **+** →「打开网页嗅探视频…」，在内置浏览器里播放视频，软件把视频地址（HLS / DASH / 视频文件）抓出来下载
- **解析内核自动更新**：有新内核时在后台下载好，重启后生效；解析失败、像是内核过期时会马上检查，卡片上出现「更新内核后重试」；新增「预览版」更新通道
- [电脑版] **YouTube 组件按需下载**：不用再自己装 Node.js / Deno，第一次解析 YouTube 链接时自动下载（约 40MB，只需一次）
- **「显示功能说明」开关**：关掉后每个选项下面解释功能的小字不再显示，界面更干净；状态、错误和警告不受影响
- **新的更新提示**：有新版本时不再弹窗打断，只出现一条「新版本 x.y.z · 查看」；点开能看到按 新功能 / 改进 / 修复 分组的更新内容
- [电脑版] **软件内更新**：在更新窗口里点「下载并安装」，下载、校验、安装、重新打开一步完成（用安装包装的才有）
- [安卓版] **弹幕版 120 帧可调**：手机的 H.264 编码器跑不了 4K 120 帧时，可以选「允许 H.265」或「保持 120 帧」（分辨率降一档）；选好清晰度后会提前告诉你实际按多少帧生成

### 改进
- **登录信息加密保存**：B站登录、网站 Cookie 不再明文存放（电脑版用 Windows 自带的 DPAPI，安卓版用 Android Keystore），升级后原有的登录信息会自动加密
- [电脑版] 侧边栏、解析结果、历史记录、设置页的滚轮滚动改成平滑滚动
- [电脑版] 同时下载很多任务、一次加入几百个视频时界面不再发涩；封面缓存有了上限，长时间开着占用的内存更少
- [电脑版] 生成弹幕版时不再拖慢电脑上别的程序；4K 视频的弹幕版默认最高 60 帧；临时文件放在下载目录，不占系统盘
- [电脑版] 所有弹窗（退出确认、重复下载、缺少 ffmpeg……）换成和软件风格一致的窗口
- [电脑版] 缩到托盘后减少后台刷新
- [安卓版] 弹幕版降帧或失败时会说明真实原因，任务卡片上可以看「弹幕版详情」（实际用的编码器、分辨率、帧率）
- [安卓版] 登录信息不参与系统的云备份和换机迁移
- 报错提示改成新的登录方式；日志里的签名参数、登录 Cookie、Windows 用户名自动打码，复制出来反馈问题更放心

### 修复
- [电脑版] 退出软件后 ffmpeg 等后台进程可能还在运行
- [电脑版] 「从浏览器读取 cookies」模式每次解析、下载都要重新读一遍浏览器，又慢又容易失败
- [电脑版] 不同网站 id 相同的视频被误判成「已经在下载列表里」；片段在下载时整段下不了
- [电脑版] 改编码偏好、HDR 开关或字幕语言后，手动选好的清晰度被重置
- [电脑版] 历史搜索里输入 `%` 或 `_` 时结果不对
- [电脑版] 清晰度下拉框里的锁、「已下载」的对勾在深色模式下颜色不对
- [安卓版] 4K 视频生成 120 帧弹幕版时误报「这台手机不支持 120 帧」：实际原因是 HDR 视频不能画弹幕，或者两个弹幕版同时生成时互相抢编码器；现在会排队生成、失败自动降到 60 帧再试，并给出准确的说明

## 注意
- 升级后第一次打开，软件会把原来的登录信息（B站、网站 cookies）加密保存并删除明文文件；之后如果退回 2.4.1 或更早的版本，需要重新登录。
- 程序没有购买代码签名证书，Windows 可能弹出“已保护你的电脑”，点“更多信息 → 仍要运行”即可。
- 免安装版不要只拷贝 exe，整个文件夹（含 `_internal`、`ffmpeg`）都需要。
- 账号都需在软件里自己登录；登录信息只保存在你自己的设备上。
